The terms above relate to **LOLRMM** (Living Off the Land Remote Monitoring and Management), an open-source, community-driven project maintained by **MagicSword-io** on GitHub (`magicsword-io/LOLRMM`)[1][2].

### What is LOLRMM?
Similar to projects like LOLBAS (Living Off the Land Binaries and Scripts) or LOLDrivers, **LOLRMM** is a curated catalog and intelligence resource that tracks legitimate Remote Monitoring and Management (RMM) and remote access software[1][3][4]. 

While these tools are essential for IT administrators and help desks, threat actors, ransomware gangs, and Advanced Persistent Threat (APT) groups frequently abuse them to maintain stealthy persistence, move laterally, and control compromised networks under the guise of legitimate administrative traffic (a "Living Off the Land" technique)[5][6].

### The Tools Listed (**AnyDesk, TeamViewer, RustDesk, ScreenConnect, Splashtop**)
The specific applications you mentioned—**AnyDesk**, **TeamViewer**, **RustDesk**, **ConnectWise ScreenConnect**, and **Splashtop**—are prime examples of software cataloged within LOLRMM[6]. The project provides:
* **Metadata & Artifacts:** Details on installation paths, default ports, registry keys, and file artifacts left behind by these tools[3].
* **Abuse Context:** Documentation on how attackers weaponize them for initial access or persistence[6].
* **Detection Rules:** Sigma rules, API endpoints, and hunting queries (such as for Microsoft Defender or Splunk) to help security teams spot unauthorized or malicious instances of these tools running in corporate environments[7][8].
