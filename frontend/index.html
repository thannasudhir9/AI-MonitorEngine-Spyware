2. AdBlocker Network Proxy: Intercepts HTTP/HTTPS traffic at 127.0.0.1:8080, matching domain names against ad/telemetry blacklists.

Windows UAC Elevation Handling

When a target process (such as PID 5824) is protected by SYSTEM or kernel tokens, standard user processes cannot terminate it. AegisShield acquires SeDebugPrivilege and provides an interactive Elevated UAC Eradicator that invokes Start-Process taskkill -ArgumentList '/F /T /PID <pid>' -Verb RunAs -Wait, presenting the Windows UAC confirmation dialog to kill elevated malware cleanly.

Command: taskkill /F /PID <PID> (or double click start_all_admin.bat)
