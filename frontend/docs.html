Section 03

The Four Core Defensive Engines

1. AI Monitoring Engine (Threat Hunter)

Scans running processes, parent-child hierarchies, binary headers, and loaded modules. Calculates cumulative anomaly scores (0-100) using 6 core detection layers: Signature Matching, Masquerade Detection, LOLRMM / Remote Desktop tools, Temporary Directory execution, Suspicious Command-Line flags, and Policy Rules.

2. AdBlocker Engine (Network Interceptor)

Runs on 127.0.0.1:8080. Integrates directly into Windows Internet Settings via winreg (ProxyEnable=1). Blocks ad servers, telemetric trackers, malware distribution domains, and crypto-miners. Returns synthetic 204 No Content or 1x1 transparent GIFs without crashing client applications.

3. Web Tracker & Origin Tracer

Logs all visited URLs, HTTP methods, client IPs, and status codes with millisecond date and time. Performs reverse DNS and ASN/ISP queries to classify remote endpoints into Verified CDNs, Trusted Infrastructure, or Suspicious Hosters. Features Private Stealth Mode which prevents writing to disk and suppresses tracking headers.

4. Process Monitor & Remediator

Provides deep inspection of process PE headers, loaded DLLs, listening sockets, and security tokens. Implements a multi-tier failover termination engine: psutil -> taskkill /F -> PowerShell force -> Windows Service Control -> Interactive Administrator UAC Elevation.

Section 04

Administrator Elevation & Remediation Architecture

Windows enforces strict process token boundaries. When a target PID is owned by the SYSTEM account or runs inside a protected Windows Service, standard user processes receive Access Denied. AegisShield overcomes this boundary through:

1. SeDebugPrivilege Acquisition

Upon startup, the Python backend invokes ctypes.windll.advapi32.AdjustTokenPrivileges to grant itself Windows Debug Rights.

2. Service Control Interceptor

If a process PID is tied to a Windows Service, AegisShield discovers the service name via WMI/CIM and commands sc stop <svc>.

3. Elevated UAC Eradicator

Clicking "⚡ Trigger Elevated UAC Eradicator" executes Start-Process taskkill -ArgumentList '/F /T /PID <pid>' -Verb RunAs -Wait, presenting the Windows UAC confirmation dialog to kill elevated malware cleanly.

4. 1-Click Admin Launchers

Double-clicking start_all_admin.bat launches the entire suite with elevated token rights, removing all access denied restrictions permanently.
